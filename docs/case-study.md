# Engineering case study: NigerFlora BioSciences

## Problem
Computational pharmaceutical research needs transparent descriptors, reproducible comparisons and explicit limits on interpretation.

## Approach
Separate measured properties from predictions, track units and provenance, validate inputs, and distinguish preliminary computational results from experimental evidence.

## Portfolio evidence
The independent example calculates absolute prediction error and mean absolute error for fictional log-solubility records expressed as log10(mol/L). These are synthetic values, not published measurements or results of NigerFlora's production model. The example does not calculate molecular descriptors, predict solubility, perform docking, establish drug safety or recommend treatment.

## Interview topics
Scientific data validation, uncertainty, reproducibility, model evaluation, data privacy and responsible biomedical software design.
